라우트 데이터 구조

푸시 알림의 data 필드에 포함되는 라우팅 정보:

{ wrId: "게시글ID" }
💡 사용 방법: 앱에서 푸시 알림 클릭 시 data.wrId 값을 파싱하여 해당 게시글 상세 화면으로 이동합니다.

게시판별 푸시 발송 상세

📢 공지사항 (board-notice)

  • 게시글 작성 all (전체) 
await pushService.sendToTopic(
    'all',
    ctx.dto.caName,       // 카테고리명
    ctx.dto.wrSubject,    // 게시글 제목
    { wrId: String(post) }  // 라우트 데이터
);

💬 민원제안 (board-suggest)

  • 게시글 작성 상위 부서 (Topic)
  • 부서 이관 (pass) 대상 부서 대상 멤버
  • 댓글 작성 게시글 작성자
  • 대댓글 작성 원댓글 작성자

⚠️ 위험신고 (board-risk)

  • 게시글 작성 부서 28 상위 부서
  • 댓글/대댓글 작성 게시글 작성자

📚 교육 (board-edu)

  • 게시글 작성 wr6, wr7 필드의 멤버들
  • 댓글/대댓글 작성 게시글 작성자

📖 매뉴얼 (board-manual)

  • 게시글 작성 (wr1='기술직') tech
  • 게시글 작성 (wr1='행정직') office
  • 게시글 작성 (기타) all
  • 댓글/대댓글 작성 게시글 작성자

토픽(Topic) 정의

토픽명 대상 설명
all 전체 사용자 optIn=true인 모든 디바이스 토큰 보유자
office 행정직 mb5 = '행정', '경영지원', '안전관리'
tech 기술직 mb5가 행정직 제외인 사용자
{부서ID} 특정 부서 해당 deptSite.id에 속한 멤버들

앱에서의 라우팅 처리 예시

// Flutter 예시
FirebaseMessaging.onMessageOpenedApp.listen((message) {
    final wrId = message.data['wrId'];
    if (wrId != null) {
        Navigator.pushNamed(context, '/post/detail', 
            arguments: { 'wrId': wrId });
    }
});

// React Native 예시
messaging().onNotificationOpenedApp((remoteMessage) => {
    const { wrId } = remoteMessage.data;
    if (wrId) {
        navigation.navigate('PostDetail', { wrId });
    }
});
⚠️ 참고: 현재 wrId만 전달되고 있어 게시판 종류(boardType)는 별도로 전달되지 않습니다. 앱에서 게시판 종류를 구분해야 할 경우 boardType 필드를 추가하는 것을 권장합니다.

핵심 코드 패턴

// 게시글 생성 후 훅 (afterCreatePost)
protected override async afterCreatePost(post: any, ctx: any) {
    await this.pushService.sendToTopic(
        'all',                           // 또는 부서 ID
        String(ctx.dto.caName ?? ''),    // 알림 제목
        String(ctx.dto.wrSubject ?? ''), // 알림 본문
        { wrId: String(post) }           // ✅ 라우트 데이터
    );
}

// 댓글 생성 후 훅 (afterCreateComment)
protected override async afterCreateComment(comment: any, ctx: any) {
    await this.pushService.sendToUser(
        ctx.mbNo,                          // 게시글 작성자 mbNo
        '댓글 알림',                      // 알림 제목
        String(ctx.dto.wrContent ?? ''),  // 댓글 내용
        { wrId: String(ctx.parentId) }    // ✅ 원글의 wrId
    );
}
