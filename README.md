## 🚀 빠른 시작 (Quick Start)

### 설치 (Installation)
```bash
$ npm install
```

### 실행 (Running the app)
```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

### 테스트 (Test)
```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e
```
